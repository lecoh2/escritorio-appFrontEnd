Configuração Financeira

Defina as metas financeiras utilizadas no dashboard do escritório.

Metas Financeiras

Configure a meta mensal e a meta anual do escritório.

Como funcionam as metas?

A Meta Mensal pode ser definida manualmente ou calculada automaticamente pelo sistema com base no histórico de recebimentos do escritório.
A Meta Anual representa o objetivo financeiro planejado para o ano e pode ser definida conforme o planejamento do escritório.

Meta Mensal
Meta de recebimento para o mês.
R$
Caso utilize a meta automática, o sistema calculará esse valor com base no histórico de recebimentos.
Meta Anual
Meta financeira planejada para o ano.
R$
Utilize este valor como referência para o planejamento financeiro anual do escritório.
Meta Automática
O sistema calcula automaticamente a meta mensal utilizando o histórico real de recebimentos do escritório.
